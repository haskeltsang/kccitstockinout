Keyboards and mice have no asset tags — add them by quantity. Everything else is tracked per unit and comes in from an Excel or CSV file.

Add keyboards or mice by quantity

Each type is one item — Mouse (Wired), Mouse (Wireless), Keyboard (Wired), Keyboard (Wireless) — created the first time you add it. On the Stock In / Out pages, move them by typing their SKU: MS-WIRED, MS-WIRELESS, KB-WIRED or KB-WIRELESS.

Import tracked assets from Excel

Upload your asset list and every row becomes one tracked unit in the storeroom — no need to set up items first. Rows whose Asset/EAM no. or S/N is already registered are skipped, so re-importing the same file is safe.

One row per unit, with a header row: Item, Model, S/N, Asset/EAM No.. Item is the category (e.g. Printer, PC, Laptop, Monitor) and Model is the exact product — rows with the same Item + Model group under one item. Model is required, and at least one of S/N or Asset/EAM No. — new stock often has only an S/N; leave EAM blank until tagged. Brand, Funding, Project, Project Code and Site (Site A or Site B — blank means Site B) columns are optional. Format code columns as Text in Excel so leading zeros are kept. Keyboards and mice are not imported here — use the quantity form above.

Recorded on every imported row in the history — for example the PO the assets came in on.
